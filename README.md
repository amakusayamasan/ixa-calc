# IXA 部隊計算

戦国IXAの攻撃部隊の素火力を計算するツールです。
武将・スキル・兵種・傑バフのマスタは Firebase(Firestore)に保存し、管理者だけが登録・編集できます。
サイトは GitHub Pages で公開します。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ツール本体(計算画面・マスタ管理) |
| `firebase-config.js` | Firebase の接続設定(手順2で書き換える) |
| `firestore.rules` | データを守るセキュリティルール(手順3で Firebase に貼り付ける) |
| `seed/master.json` | 初期データ(Claude 版で登録していた武将5・スキル3・兵種11・人数280) |

## 公開までの手順

### 1. GitHub Pages を有効にする

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして **Save**
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります
   (この時点では「Firebase の設定がまだです」と表示されれば正常です)

### 2. Firebase プロジェクトを作り、設定を書き込む

1. https://console.firebase.google.com/ を開き、**プロジェクトを作成**(名前は例:`ixa-calc`。Google アナリティクスはオフで構いません)
2. プロジェクトのトップで **ウェブアプリを追加**(`</>` アイコン)。名前は任意、Firebase Hosting のチェックは不要
3. 表示される `firebaseConfig` の値を、`firebase-config.js` の該当箇所にそのままコピーしてコミット

### 3. データベースとログインを有効にする

1. **構築 → Firestore Database → データベースを作成**
   - ロケーション:`asia-northeast1(東京)`
   - 「本番環境モード」で作成
2. Firestore の **ルール** タブを開き、`firestore.rules` の中身を全部貼り付けて **公開**
3. **構築 → Authentication → 始める → Sign-in method** で **Google** を有効にする
4. **Authentication → 設定 → 承認済みドメイン** に `<ユーザー名>.github.io` を追加

### 4. 自分を管理者に登録する

1. 公開したサイトを開き、右上の **管理者ログイン** から Google アカウントでログイン
2. 「管理者として登録されていません」という案内と **ユーザーID** が表示されるので、コピーする
3. Firebase コンソールの **Firestore Database → データ** で
   - **コレクションを開始** → コレクションID:`admins`
   - **ドキュメントID**:コピーしたユーザーID
   - フィールドは何でも構いません(例:`role` = `admin`)
4. サイトを再読み込みすると、右上が「管理者」になります

### 5. 初期データを入れる

管理者でログインした状態で **マスタ管理** を開くと「初期データを投入」ボタンが出ます。
押すと Claude 版で登録していたマスタがそのまま入ります。
以降は Excel(武将データ・スキルデータのシート)からの取り込みや、画面での編集で更新できます。

### 6. みんなに共有する

サイトの URL を共有するだけです。ログインしなくても計算とマスタの閲覧ができます。
組んだ編成は、それぞれのブラウザに保存されます。

## よくある質問

**Q. `firebase-config.js` の API キーを GitHub に公開して大丈夫?**
A. 大丈夫です。この値はサイトを開いた全員のブラウザに送られるもので、秘密の鍵ではありません。
データの書き込みは `firestore.rules` で「admins に登録された人だけ」に制限しています。

**Q. 管理者を増やしたい**
A. その人にサイトでログインしてもらい、表示されたユーザーIDを `admins` コレクションに追加してください。

**Q. 料金は?**
A. Firebase の無料プラン(Spark)で動きます。読み込みは1日5万回まで無料で、1回開くと約20回読み込むので、1日2,000回程度開いても無料枠内です。

**Q. マスタのバックアップは?**
A. Firestore コンソールから確認できます。Excel を元データとして持ち続け、必要なら「Excelから取り込み」で作り直せます。
